# Supported SQL

SQL statements that can be parsed (backend) and rendered (frontend).

## Supported

- `CREATE TABLE`
- `ALTER TABLE ADD COLUMN`
- `ALTER TABLE DROP COLUMN`
- `ALTER COLUMN TYPE`
- `SET NOT NULL`
- `DROP NOT NULL`
- `SET DEFAULT`
- `DROP DEFAULT`
- `RENAME TABLE`
- `RENAME COLUMN`
- `ADD CONSTRAINT` (PRIMARY KEY, UNIQUE, FOREIGN KEY, CHECK, EXCLUDE)

## Not Supported

- `DROP CONSTRAINT`
